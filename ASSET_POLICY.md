# Asset policy

Supply your own lawfully obtained disc files for local use. Keep extracted discs, game-derived code, sound, models, textures, gameplay screenshots, menus, saves, personal seeds, private signing material and built packages out of the public repository. Original and Full APKs can contain the complete private game payload. A Windows binary can include translated guest code. Keep both private. Directory names and checksums here identify required inputs for verification. They do not grant rights in them.

The included preview image is a capture of toolkit-owned source code. The verifier accepts its exact path and SHA-256. Gameplay images, music and footage can carry separate rights. Review the rights in a specific capture before adding it to any public material. The two Android APKs and the Windows game executable remain personal build products.

The interface code and resource recipes can be reviewed separately. Some Full resources still require user-supplied files of the specified digest. Review each third-party notice and provenance entry before sharing anything new.
